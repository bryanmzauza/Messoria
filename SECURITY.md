# Security

## Reporting a problem

If you find a way to harm other players or the machines that run Messoria,
such as crashing a dedicated server from outside, reading or changing another
player's saved data, or making a client run something it should not, please
report it privately through
[Report a vulnerability](https://github.com/bryanmzauza/Messoria/security/advisories/new)
on this repository's Security tab, not in a public issue.

Say what you found, how to reproduce it and which version you tried. The
report stays private until a fixed release is out.

## Versions

Only the latest release is fixed. A server should run the same version as the
players who join it.
